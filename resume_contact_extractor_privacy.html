Resume Contact Extractor Privacy

App Name

Resume Contact Extractor.

What this app does

It extracts candidate contact details from raw resume text into a deterministic structured format.

When to use it

Use it for read-only recruiting workflow extraction when resume contact fields need to be structured.

Input

The app accepts only raw resume text in text.

Output

The app returns candidate name, email, phone, city, missing fields, source text, and structured errors.

What this app does not do

It does not evaluate candidates, rank candidates, provide hiring advice, contact candidates, schedule interviews, send messages, update ATS systems, or make hiring decisions.

Data handling

The app does not store submitted text, does not call external APIs, does not require authentication, and does not maintain state.
