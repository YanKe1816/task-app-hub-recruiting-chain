Candidate Time Extractor Terms

App name

Candidate Time Extractor.

What this app does

It performs deterministic extraction of candidate interview availability details from user-provided text.

When to use it

Use it when a recruiting workflow needs structured availability data from a candidate message.

Input

Provide the raw candidate message as text.

Output

The app returns structured availability fields, missing field indicators, source text, and structured errors.

What this app does not do

The app does not schedule interviews, send communications, update ATS records, judge candidates, rank candidates, or make hiring decisions.

Data handling

The app is stateless and read-only. Users are responsible for deciding what candidate text to submit.
