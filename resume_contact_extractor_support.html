Resume Contact Extractor Support

App Name

Resume Contact Extractor.

What this app does

It extracts candidate contact details into structured fields for a recruiting workflow.

When to use it

Use it when supplied resume text needs deterministic extraction into contact fields.

Input

Submit a JSON-RPC tools call with arguments.text containing raw resume text.

Output

The output contains status, candidate_name, email, phone, city, missing_fields, source_text, and errors.

What this app does not do

It does not evaluate candidates, rank candidates, provide hiring advice, contact candidates, schedule interviews, send messages, update ATS systems, or make hiring decisions.

Data handling

The app is read-only, stateless, deterministic, and uses no external APIs.

Support

Email sidcraigau@gmail.com when reporting an issue. Include the app route, MCP method, input category, and returned error message. Do not include sensitive candidate data unless necessary.
