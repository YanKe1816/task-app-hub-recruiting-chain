Resume Contact Extractor

App Name

Resume Contact Extractor.

What this app does

This app extracts candidate contact details from raw resume text into fixed structured fields: candidate name, email, phone, city, missing fields, source text, and errors.

When to use it

Use it when a recruiting workflow needs deterministic structured extraction of contact fields from resume text.

Input

The input is a single text field named text containing raw resume text provided by the user.

Output

The output includes status, candidate_name, email, phone, city, missing_fields, source_text, and errors.

What this app does not do

It does not evaluate candidates, rank candidates, provide hiring advice, contact candidates, schedule interviews, send messages, update ATS systems, or make hiring decisions.

Data handling

The app is stateless, read-only, deterministic, and does not use external APIs. It processes only the text supplied in the current request.
